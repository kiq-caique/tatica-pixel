# Tática Pixel

Fichas de personagem e tabuleiro tático em pixel art (estilo Final Fantasy Tactics / Shining Force), com combate por dados e perfil de mestre.

Jogar: https://kiq-caique.github.io/tatica-pixel/

Tudo roda em um único `index.html`, sem dependências. Os dados ficam salvos no navegador (use o botão **Backup** para exportar/importar).
